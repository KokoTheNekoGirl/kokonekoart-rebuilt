  - title: Context & Inspiration
    content: |
      During college, we were assigned to create a React Native project connected to an API with 2 tabs/pages. It was a two-person project.

      Of course, upon finding there was a [PokéAPI](https://pokeapi.co/), I just had to use it for the project. We discussed what we could do with it and ultimately we opted for a Pokémon randomizer that displays the PokéDex entry on the second tab.
    images:

    content: |
      We started with Hello Expo and took off from there. We split the group work equally between the two of us. I tasked myself with the API fetch, creating the visual assets, and completing the encounter page. 2 years later, I polished it up with additional Pokémon type & base stat styles.
